The "Not Found" error occurs because OpenCode connects to OpenAI-compatible third-party APIs using the standard /v1/chat/completions endpoint.BeatAPI uses non-standard endpoints (such as /v1/responses or asynchronous task endpoints) depending on the model tier, which causes standard Chat Completions requests sent to [https://api.beatapi.io/v1/chat/completions](https://api.beatapi.io/v1/chat/completions) to return 404 Not Found.   Solution: Use Official OpenCode Native ProvidersTo resolve this issue, use a provider with built-in native support for OpenCode (such as OpenAI, DeepSeek Direct, or OpenRouter):Option 1: DeepSeek Official API Direct (Recommended)You can connect directly to DeepSeek's official API in opencode.json:JSON{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "deepseek": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "DeepSeek",
      "options": {
        "baseURL": "https://api.deepseek.com/v1",
        "apiKey": "YOUR_DEEPSEEK_API_KEY"
      },
      "models": {
        "deepseek-coder": {
          "name": "DeepSeek Coder"
        },
        "deepseek-chat": {
          "name": "DeepSeek Chat"
        }
      }
    }
  }
}
Option 2: OpenRouter (Supports DeepSeek & 100+ Models)If you want a multi-model aggregator that works seamlessly with OpenCode:JSON{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "openrouter": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "OpenRouter",
      "options": {
        "baseURL": "https://openrouter.ai/api/v1",
        "apiKey": "YOUR_OPENROUTER_API_KEY"
      },
      "models": {
        "deepseek/deepseek-chat": {
          "name": "DeepSeek V3"
        }
      }
    }
  }
}
Steps to ApplyOpen opencode.json in Antigravity IDE.   Replace its content with one of the compatible configurations above.Save the file and restart your prompt session (Ctrl + P $\rightarrow$ Switch Model).
